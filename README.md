## Technische Vereisten ✓

- ✅ Zelfstandige HTML files (geen externe afbeeldingen/JS-dependencies)
- ✅ Google Fonts only (met system font fallbacks)
- ✅ Inline CSS & SVG's
- ✅ JSON-LD schema (Restaurant/HairSalon)
- ✅ Open Graph + Twitter Card meta tags
- ✅ WCAG AA contrast (4.5:1 minimum)
- ✅ aria-labels, aria-hidden, semantic HTML5
- ✅ Touch targets min 44×44px
- ✅ Mobile-first responsive
- ✅ prefers-reduced-motion support
- ✅ Click-to-call links (tel:)

2. Sleep elk HTML-bestand naar de zone
3. Klaar!
